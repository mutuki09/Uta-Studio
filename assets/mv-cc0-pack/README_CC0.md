# MV用 CC0 素材パック

このフォルダの画像は、KenneyがCreative Commons CC0で配布している素材から選択・構成したものです。商用利用、加工、再配布が可能で、クレジットは必須ではありません。

## 出典

- Background Elements: https://kenney.nl/assets/background-elements
- Toon Characters: https://kenney.nl/assets/toon-characters
- Planets: https://kenney.nl/assets/planets
- CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

## 内容

- 01_backgrounds: 背景6枚、1920×1080。Background Elementsから構成。
- 02_main_images: 惑星5枚、透過PNG。
- 03_characters: キャラクター8枚、透過PNG・HD。

背景はCC0素材を組み合わせてこのパック用に構成しています。ずんだもん・四国めたんの公式素材はCC0ではないため、このパックには含めていません。
