# 歌スタジオ / AI譜面スタジオ・和声ラボ

曲案を読み込み、聴いて、直して、持ち出すためのローカル音楽制作ツールです。

曲名と日本語歌詞から3つの曲案を作れるほか、曲シート、MIDI、MusicXML、Blueprint JSONを読み込んで、メロディ、コード、楽器編成、ドラムを画面上で調整できます。歌詞のないゲームBGMにも利用できます。

## 主な機能

- 曲名と歌詞から、方向性の異なる3つの曲案を作成
- MIDI、MusicXML、曲シート、Project、Blueprint JSONの読み込み
- SoundFontによるブラウザ内試聴
- ピアノロールでの音程調整
- コード進行、楽器編成、ドラムパターンの編集
- 短すぎる音、息継ぎ、音域、跳躍、コードとの関係などを診断
- 理論補助と従来処理の切り替え、A/B試聴
- NEUTRINOによる日本語歌唱の生成
- ローカルDemucsによる歌声分離
- MIDI、MusicXML、OpenUtau USTX、Project v2、伴奏・歌声WAVの書き出し
- 現在の曲と画像を使った、拍同期MVのプレビューと動画保存
- ローカルのMVスタジオ起動時は、8系統の演出・背景・色調整・1080p MP4出力へ自動接続

## CodexやClaudeなどのAIと使う

画面から作曲依頼用の指示をコピーし、Codex、Claude、ChatGPTなどのAIに曲シートやBlueprintを作成させ、その回答を貼り付けるかファイルとして読み込めます。AIが作った案をこのツールで試聴し、必要な部分だけ手元で修正できます。

AIサービスへ自動送信する機能やAPIキーの保存機能はありません。AIへ渡す内容は利用者が自分で選びます。

## 起動

Node.jsが利用できる環境で、このフォルダを開いて次を実行します。

```powershell
node serve.mjs
```

ブラウザで <http://127.0.0.1:4193/> を開きます。サーバーはPC内からだけ接続できる `127.0.0.1` で待ち受けます。

MV制作はブラウザ単体でも利用できます。MVスタジオを `127.0.0.1:4195` で起動している場合は、高機能な制作画面へ自動で切り替わります。

## 歌声生成と音声分離

画面と内蔵SoundFontはこのリポジトリだけで動作します。NEUTRINO歌唱とDemucs分離は、別途用意したローカルエンジンを `127.0.0.1:4190` で起動して利用します。NEUTRINO本体、歌声モデル、Demucsはこのリポジトリに含まれません。

歌声・分離用のデータはローカルエンジンへ送られ、外部サーバーにはアップロードされません。GitHub Pagesなど静的ホスティング上では、これらのローカル機能は利用できません。

## 和声補助

画面上部で「理論補助」と「従来の処理」を切り替えられます。選択は新規作曲、伴奏の再生成、診断に反映されます。読み込んだ曲の音符を切り替えだけで変更することはありません。

理論補助には、コード構成音を保った伴奏配置、半小節のコード変更に沿った配置、経過音・隣接音候補を考慮した参考診断を実装しています。SoundQuestや『総合和声』の教材本文、譜例、音源は収録していません。

## 制限

- MIDIのテンポ変化、SysEx、細かな演奏制御を完全には再現しません。
- MusicXMLは一般的な音符、歌詞、テンポ、コードを中心に読み込みます。
- 厳密な四声体、転調、掛留の判定は未実装です。
- 自動診断は候補を示す機能です。最終判断は伴奏と一緒に試聴して行ってください。

## テスト

```powershell
node test.mjs
```

元版との一致検査も行う場合は、元版フォルダを環境変数 `AI_SCORE_ORIGINAL_DIR` で指定します。
